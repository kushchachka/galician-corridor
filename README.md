Gallician Corridor - це 2D гра, створена в Godot, про студентку, яка блукає коридорами галицького коледжу, намагаючись вижити серед пар, викладачів і дивних ситуацій студентського життя.

Опис

Ти граєш за студентку, яка щодня проходить через один і той самий (але щоразу трохи інший) коридор коледжу. Досліджуй аудиторії, взаємодій з персонажами та приймай рішення, які впливають на розвиток подій.

Рух	  стрілки
